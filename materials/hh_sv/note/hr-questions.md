Стек: Java 17, Spring Boot 3.x, PostgresSQL.

## Что мы от тебя ждем:

- Опыт коммерческой разработки на Java от 3 лет;
- Уверенные знания Java 8–17+, Spring;
- Опыт работы с PostgreSQL, Redis, Kafka;
- Базовые знания HTML, CSS, JavaScript, React, jQuery. - `вы ищите fullsteck? много ли фронтенда?`
